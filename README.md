# Train Profile Builder | Technical Case Study

A technical showcase of an RFID-based train profiling system developed during my internship with the RFID team at the Centre for Railway Information Systems (CRIS).

## Overview

The Train Profile Builder addresses the challenge of reconstructing train consists using RFID tag reads and Train Presence Detection (TPD) sensor events.

The system explores how sensor events can be processed and validated to construct an ordered representation of train assets and present the resulting profiles through a dashboard.

This repository is a documentation-focused portfolio showcase. It does not contain the original application source code.

## Key Engineering Areas

- Sensor-event processing and axle segmentation
- Time-window-based RFID matching
- Train-consist reconstruction
- Sensor-event validation
- Machine learning with Random Forest
- Dashboard-based profile visualization

## Technology Stack

- Python
- pandas
- scikit-learn
- Flask
- PostgreSQL
- HTML and CSS

## System Workflow

1. Process sensor events and RFID reads.
2. Identify axle groups and associate relevant RFID reads.
3. Construct an ordered train profile.
4. Validate the available sensor information.
5. Present train profiles and validation results through a dashboard.
